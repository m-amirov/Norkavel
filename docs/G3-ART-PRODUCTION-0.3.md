## Что реализовано в исходном коде

1. `web/art-registry.mjs`: явная карта четырёх допустимых ассетов, проверка ID, относительного пути, размеров, SHA в манифесте, уникальности и статуса `CANDIDATE_INTEGRATED`.
2. `web/main.mjs`: опциональная асинхронная загрузка только реально зарегистрированных WebP, рисование на Canvas; если файлов нет, используются прежние геометрические временные фигуры. Существующая сцена, управление, telegraph босса и PvE сохранены.
3. `scripts/serve.mjs`: `/assets/art/manifest.json`, JS-реестр и строго разрешённые WebP, причём только если файлы присутствуют при старте сервера; отсутствие ассета не превращается в запрос 404 из игрового кода.
4. `scripts/import-g3-art.mjs`: детерминированный импорт **всех четырёх** WebP из распакованного архива. Сначала проверяет точный SHA-256, RIFF/VP8X, RGBA alpha, 512×512 и весь комплект, затем добавляет файлы и записи в реестр. Импорт не меняет `gates.artistic`, `gates.rights` или `gates.animation`.
5. Тесты `art-registry`, `import-g3-art`, `web` и browser-smoke отделяют `STAGED_NOT_COMMITTED` от действительно интегрированного и декодированного в Canvas изображения.

## Как активировать подготовленный арт-пакет

Это следующие **не выполненные** действия: ZIP доступен как артефакт разговора, а не GitHub-файл.

```powershell
# После распаковки архива в указанную директорию:
node scripts/import-g3-art.mjs "C:\\path\\to\\Norkavel-G3-Companions-0.3" --dry-run
node scripts/import-g3-art.mjs "C:\\path\\to\\Norkavel-G3-Companions-0.3"
npm run check
npm run test:browser
```

После фактического импорта нужны source-controlled PNG или права на оригиналы, commit в `main`, успешный CI на его exact SHA и независимый просмотр скриншотов `640×360`, `844×390`, `1280×720`. До этого **не** отмечать G3 арт как runtime-integrated.

## Незакрытые G3 требования

- Непересекающиеся **анимационные** кадры idle/attack/hit/death/victory для каждого героя и спутника; анимация одной статичной картинки трансформами не считается production-анимацией.
- Три врага и Хранитель Разлома: оригинальные прозрачные игровые мастера и отдельные фазы windup/impact/recovery. Два сгенерированных презентационных борда не являются такими ассетами.
- Арена с реальными отдельно нарисованными depth layers для parallax.
- Мобильный pixel QA (масштаб, читаемость, положение HP, предупреждение босса), производительность/decode/размер сборки и правовой реестр.
- Утверждение владельцем. G3 `BLOCKED`, `releaseReady=false`, `publicationAllowed=false`.
