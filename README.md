# Норкавель / Norkavel

2D Auto Battler + Clicker + Idle RPG для Яндекс Игр. Один выбираемый главный герой и команда из трёх спутников; PvP только асинхронный. Сражения — вид сбоку.

> **Статус:** G0/G1 — проектирование и технический bootstrap. Игра пока не играбельна; ни платформенная интеграция, ни публикация не подтверждены.
