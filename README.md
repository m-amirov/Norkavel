# Норкавель / Norkavel

2D Auto Battler + Clicker + Idle RPG для Яндекс Игр. **Один постоянный главный герой, однократно выбранный из четырёх (сменить после подтверждения нельзя)**, три спутника из **пяти постепенно открываемых**; PvP только асинхронный. Сражения — вид сбоку.

> **Статус:** G2 технически играбелен, но прототип ещё **не поддерживает** четыре главных героя на выбор и пять открываемых спутников. Требуется G2-R. G3 арт не принят; PvP, SDK и публикация не реализованы.

## Запуск локального G2

Нужны Git, Node.js 22+, современный браузер.

```bash
git clone --recurse-submodules https://github.com/m-amirov/Norkavel.git
cd Norkavel
npm run check
npm run preview
```

Откройте `http://127.0.0.1:4173`. Игра запускается без аккаунта и сервера PvP (только локальный PvE срез).
Управление: кликайте по врагам, нажимайте кнопки навыков или клавиши `1` и `2`, меняйте состав до боя. На смартфонах используйте только альбомную ориентацию.

Для браузерной диагностики (требуется Chromium/Chrome):

```bash
npm run test:browser
```

Скриншоты браузерного smoke сохраняются в `artifacts/g2-browser/` и в артефакте CI; это **не финальное игровое искусство**.

## Работа с Codex: короткие команды

В Codex, открытом в корне Norkavel, достаточно команды:

```text
Продолжай Norkavel.
```

Агент обязан начать с [AGENTS.md](AGENTS.md), [проектного процесса WFA + Ludory](docs/AGENT-WORKFLOW.md) и [текущей очереди задач](docs/TASK_QUEUE.md), самостоятельно определить ближайший доступный этап, выполнить его проверки и интегрировать в `main`. **Пользователю не нужно заново пересказывать GDD или писать новый многостраничный промт.** Наличие Git-подмодулей не запускает независимых агентов; подтверждения работы должны быть реальными.
