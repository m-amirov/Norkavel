# Норкавель — GDD (краткий индекс)

**GDD 1.1 (19.11.2026): количественные требования к составу CONFIRMED, остальной контент OPEN.**

## Концепция
Качественная браузерная 2D-фэнтези Auto Battler + Clicker + Idle RPG для Яндекс Игр. Игрок выбирает **одного из 4 разных главных героев**. Отряд: выбранный герой + **3 спутника из коллекции 5 постепенно открываемых**. Бои отображаются **сбоку**. В PvE игрок вмешивается кликом и активными скиллами; PvP — **только асинхронное**, без реального времени.

## Core loop
Собрать отряд → запустить автобой → использовать активные способности → победить/проиграть → получить награды → развить героя и спутников → новая битва/арена.

## Релизный замысел (пока гипотеза)
**4 разных главных героя, 5 спутников всего, 1+3 в бою — подтверждено.** Пять глав/50 этапов, ежедневные задания, достижения и пять PvP-лиг — пока предложения. Реальные цифры принимаются после балансировки и проверки G2/G3.
