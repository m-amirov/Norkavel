# Норкавель — GDD (краткий индекс)

**Версия 1.0 draft • 2026-11-18 • ожидает утверждения владельца.**

## Концепция
Качественная браузерная 2D-фэнтези Auto Battler + Clicker + Idle RPG для Яндекс Игр. Один выбранный главный герой возглавляет трёх спутников. Бои отображаются **сбоку**. В PvE игрок вмешивается кликом и активными скиллами; PvP — **только асинхронное**, без реального времени.

## Core loop
Собрать отряд → запустить автобой → использовать активные способности → победить/проиграть → получить награды → развить героя и спутников → новая битва/арена.

## Релизный замысел (пока гипотеза)
Четыре класса главного героя, двенадцать коллекционных спутников, пять глав/50 этапов, ежедневные задания, достижения и пять PvP-лиг. Реальные цифры принимаются после балансировки и проверки G2/G3.
