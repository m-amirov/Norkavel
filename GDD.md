# Норкавель — GDD (краткий индекс)

**GDD 1.1 (19.11.2026): количественные требования к составу CONFIRMED, остальной контент OPEN.**

## Концепция
Качественная браузерная 2D-фэнтези Auto Battler + Clicker + Idle RPG для Яндекс Игр. Игрок **однократно выбирает одного из 4 разных главных героев, после подтверждения сменить его нельзя**. Отряд: выбранный герой + **3 спутника из коллекции 5 постепенно открываемых**. Бои отображаются **сбоку**. В PvE игрок вмешивается кликом и активными скиллами; PvP — **только асинхронное**, без реального времени.

## Core loop
Собрать отряд → запустить автобой → использовать активные способности → победить/проиграть → получить награды → развить героя и спутников → новая битва/арена.

## Релизный замысел (пока гипотеза)
**4 разных главных героя, 5 спутников всего, 1+3 в бою, пятый открывается после первой победы над первым сюжетным боссом — подтверждено.** **5 глав по 10 этапов, боссы 10/20/30/40/50, 5 линейных карт и 50 уникальных боевых фонов — CONFIRMED**. Ежедневные задания, достижения и пять PvP-лиг пока предложения. Реальные цифры принимаются после балансировки и проверки G2/G3.

G2 технически играбелен, но **четыре главных героя на выбор и прогрессия пяти спутников ещё не реализованы**. Требуется G2-R, затем G3.

## Решение по открытиям
Пятый спутник открывается **только после первой победы над первым сюжетным боссом**. **Первый сюжетный босс — этап 10, CONFIRMED;** старый технический G2 босс на этапе 2 не является подтверждённым первым сюжетным боссом. **Стартовая тройка Ард/Мира/Элира утверждена**; Кайр открывается после первой победы на третьем этапе — утверждено.

**Стартовый отряд — CONFIRMED:** после постоянного выбора одного из четырёх главных героев игрок сразу получает Арда, Миру и Элиру. Они занимают три спутниковых слота. В новом профиле Кайр и пятый спутник закрыты. У старых G2 профилей ранее имевшийся Кайр должен сохраняться.

**Кайр — четвёртый спутник (CONFIRMED):** открывается после первой победы на этапе 3. Можно заменить любого из трёх активных спутников между боями. Пятый открывается после первой победы над первым сюжетным боссом.

**Пятый спутник — OWNER CONFIRMED:** ледяной контролёр с замедлением противников и ослаблением опасных атак. Открывается после первой победы над первым сюжетным боссом. Точные способности, имя, внешний вид и баланс ещё не утверждены. [Дизайн механики](docs/FIFTH-COMPANION-ICE-CONTROL-0.1.md).

**Карты кампании — CONFIRMED:** пять отдельных карт, каждая с десятью последовательно открывающимися узлами без развилок. Игрок перемещается по маршруту между узлами. Каждый из 50 этапов имеет уникальный боевой фон; отдельные 5 карт + 50 сцен = 55 обязательных художественных мастеров окружения. Боссовые фоны включены в 50. [Campaign Map 2.3](docs/CAMPAIGN-MAP-2.3.md) · [Art inventory](docs/CAMPAIGN-ENVIRONMENT-ART-0.1.md).

**Карта главы — UX CONFIRMED:** нажатие на доступную точку → короткое перемещение героя по линейному маршруту → карточка этапа → кнопка «В бой». Повтор пройденных уровней уже утверждён; детали анимации ещё не согласованы. [Campaign Map 2.3](docs/CAMPAIGN-MAP-2.3.md). Реального экрана карты пока нет.

**Повторы PvE — CONFIRMED:** ранее пройденный этап можно повторить через карту; каждая новая победа даёт уменьшенную обычную награду для ресурсов/прокачки, а first-clear бонус, Кайр, ледяной контролёр и главы повторно не открываются. Размеры выплат и лимиты пока OPEN. [Campaign Map 2.3](docs/CAMPAIGN-MAP-2.3.md).

**Прокачка — OWNER CONFIRMED 19.11.2026:** общий уровень лагеря отсутствует; каждый из пяти спутников прокачивает только свой уровень. У постоянного главного героя свой уровень, **3 способности по 4 улучшения каждая + прокачиваемая ульта**; после каждого повышения уровня игрок сам выбирает следующее улучшение. XP-числа, **максимальный heroLevel 16 CONFIRMED**, экономика и XP-пороги пока OPEN; **ульта открывается на уровне 5 и имеет 3 улучшения CONFIRMED**. [Character Progression 2.4](docs/CHARACTER-PROGRESSION-2.4.md). G2-R NOT_IMPLEMENTED.

**Прокачка спутников — OWNER CONFIRMED 19.11.2026:** каждый из пяти спутников повышает свой уровень **только вручную за золото**, без получения опыта за бой, общего лагеря или отдельных деревьев навыков спутников. Стоимость следующего уровня пока открыта, покупка списывает золото и повышает **только выбранного, уже открытого спутника**. Главный герой развивается отдельно: способ набора его уровней пока не утверждён. [Character Progression 2.4](docs/CHARACTER-PROGRESSION-2.4.md).

**Уровни героя — OWNER CONFIRMED 19.11.2026:** главный герой получает **XP за победы**, повышает отдельный уровень при достижении порога и после **каждого** повышения игрок выбирает улучшение одной из трёх способностей (каждая до 4 улучшений) или доступной ульты. Спутники XP не получают; каждый повышает свой уровень вручную за золото. **XP за повторную победу — уменьшенный, за поражение — 0 (CONFIRMED)**; точные суммы/коэффициент, численные XP-пороги и боевые эффекты ульты OPEN; **уровень открытия ульты 5 и 3 улучшения CONFIRMED**. [Character Progression 2.4](docs/CHARACTER-PROGRESSION-2.4.md).

**XP за повторные бои — OWNER CONFIRMED 19.11.2026:** главный герой получает обычный XP за первый успешный clear, **уменьшенный XP за каждую новую честную победу на уже пройденном этапе**, и **0 XP за поражение**. Спутники XP не получают, их уровни приобретаются вручную за золото. Одно и то же `attemptId` нельзя оплатить опытом повторно. Точные XP/коэффициенты OPEN. [Character Progression 2.4](docs/CHARACTER-PROGRESSION-2.4.md).

**Ульта — OWNER CONFIRMED 19.11.2026:** у выбранного главного героя она открывается **на 5-м уровне**, имеет **3 ступени улучшения**; улучшать её можно по выбору игрока вместо обычных способностей (каждая из 3 — по 4 улучшения). До уровня 5 ульта недоступна, при открытии не улучшается автоматически. Всего 15 улучшений героя, **максимальный уровень героя 16 CONFIRMED; после него новых очков не выдаётся**, XP-кривая OPEN. [Character Progression 2.4](docs/CHARACTER-PROGRESSION-2.4.md).

**Максимальный уровень героя — OWNER_CONFIRMED 19.11.2026:** начало на уровне 1, максимум **16**. Повышения до уровней 2–16 дают ровно **15 выборов улучшений**: три обычных навыка×4 и ульта×3 (доступна с уровня 5). После lvl16 нет уровня 17 или дополнительных очков; неиспользованные ранее улучшения сохраняются. XP-пороги требуют балансировки. [Character Progression 2.4](docs/CHARACTER-PROGRESSION-2.4.md). G2-R ещё не реализован.

**XP-кривая — OWNER CONFIRMED 19.11.2026:** главному герою требуются **меньшие усилия на ранних уровнях и всё больше XP для последующих**. Старт lvl1, cap lvl16, 15 осознанных skill upgrades; XP за новые победы, уменьшенный XP за повторы, 0 XP за поражение. Конкретные пороги и величины наград пока не согласованы: они должны быть рассчитаны по 50 этапам с учётом фарма. [Hero XP Pacing 2.5](docs/HERO-XP-PACING-2.5.md).
